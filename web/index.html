Most AI SEO tools make the numbers up

Ask one for search volume and keyword difficulty and you get a confident table of figures that nothing measured. You then plan a quarter of work around them. It is the most common complaint about the whole category, and it is fair.

This toolkit starts from the other end. Its main workflow reads an export of your own Google Search Console data, which is measured, free, and already yours. Anywhere a figure cannot be retrieved, it is labelled a guess. You always know which half of the answer you are reading.

The eight tools

  • Search Console auditAttach your export. Get the pages one position from page one scored by opportunity, the queries where your own URLs compete with each other, the posts quietly losing clicks, and rewritten titles for results people see but never click.
  • Traffic drop diagnosisRules things out in cost order. Starts with whether the page even renders for a crawler, which catches the JavaScript-shell problem that silently deindexes modern sites, and only reaches for "it was an update" once the mechanical causes are gone.
  • Keyword clusteringA seed keyword becomes ten themes with long-tail terms, search intent, titles and meta descriptions in one table.
  • AI citation optimisationGet quoted by AI Overviews, AI Mode, ChatGPT search and Perplexity, from Google's published guidance rather than GEO folklore.
  • Competitor gap analysisFetches the page that outranks you, proves it read it, finds what is missing, writes the replacement.
  • Content refresh auditAudits a page you own against what currently ranks. What went stale, what the winners carry that you do not, and the exact rewrites.
  • Schema markupValid JSON-LD for any type, with clear placeholders where a value is unknown. It never invents a price, rating or date, because wrong markup is worse than none.
  • Article draftA first draft a human finishes, ending with the three things only you can add.

What it refuses to tell you

Google publishes an AI optimisation guide that contradicts most of what is sold as GEO and AEO. These workflows encode the guide, not the folklore, and will push back if you ask for any of it:

Commonly soldWhat is actually true
Add an llms.txt fileGoogle Search ignores them
Chunk content for machinesNo requirement to break content into fragments
Write in a special style for AIWrite for readers; there is no AI dialect
Structured data is required to be citedIt aids rich results, it is not an entry requirement
Publish fresh content to get citedAcross 1.4M prompts, the average cited page was ~500 days old

Two findings the toolkit does hold to. A page must be indexed and eligible to show with a snippet before it can appear in a generative answer, so ranking is the entry fee rather than a parallel track. And title, snippet and URL decide whether a page is opened at all, so those get fixed before anyone rewrites body copy.

Install

In Claude, open Customize › Plugins, then Add › Add marketplace, and enter:

Bishwas-py/ai-seo-toolkit

Select AI SEO Toolkit, then Add. That is the whole thing. It covers chat on web, desktop and mobile, Cowork and Claude Code from one account, and updates itself.

If you live in the terminal:

/plugin marketplace add Bishwas-py/ai-seo-toolkit
/plugin install ai-seo-toolkit@webmatrices

Prefer a toolbar above the chat box on claude.ai and chatgpt.com? The same workflows ship as a Chrome extension.

Pair it with MCP Browser

Every workflow that touches a URL has to fetch the page and prove it read it. A plain HTTP fetch cannot tell a genuinely thin page from one that only looks empty to a fetcher, and that difference is the entire diagnosis when a site is rendering through JavaScript.

MCP Browser drives real Chrome using your signed-in session, so the toolkit can render JavaScript, fetch both ways and compare, and read the places SEO is actually discussed: Reddit, BlackHatWorld, Dev.to, forums behind a login. When you are diagnosing a drop, "did anyone else see this on the same date" is often the fastest way to separate a site problem from an algorithm one.

brew install --cask bishwas-py/tap/mcpbrowser

macOS on Apple Silicon. Free for 50 requests a day. The toolkit works without it and will say so when it could not verify rendering.

Questions

Do I need an API key or a paid SEO subscription?

No. The toolkit sends instructions to whichever AI client you already use, so the thinking runs on your existing Claude or ChatGPT plan. There is no account, no API key and no server. Free plans work.

Where does the data come from if there is no SEO database?

From your own Google Search Console export, which is free and measured. The Search Console audit reads that file directly. Anywhere a figure cannot be retrieved it is labelled a guess.

Which AI clients does it work with?

One install covers them all. Adding the plugin to your Claude account makes it available in chat on web, desktop and mobile, in Cowork, and in Claude Code, with no second setup. A Chrome extension separately covers claude.ai and chatgpt.com with a toolbar above the chat box.

What is the difference between this and an SEO prompt pack?

A prompt pack pastes text. These workflows must fetch a page and prove they read it before writing about it, separate measured numbers from guesses, and refuse to recommend tactics Google has publicly said do not work.

Is it really open source?

MIT. The workflows are plain text in the repository, so you can read exactly what is being asked of the model, change it, or lift the parts you want.
